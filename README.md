# Wine Quality: Comparative Exploratory Data Analysis

**Student:** Podisetty Balaji  
**Course:** Artificial Intelligence  
**Project format:** Jupyter notebook with Python source export

## Project overview

Compare the physicochemical profiles and ordinal quality scores of red and white wines, identify associations and distribution differences, and screen for unusual observations without treating statistical patterns as causal explanations.
